# 多益衝分站：網站版

用一般瀏覽器就能打開，可以加到手機主畫面當 App 用。頁面和題庫打開過一次後就存在裝置裡，沒網路也能練；音檔則是播放過一次後才存下來。手機和電腦可以用「同步碼」同步進度。

## 資料夾內容

- `public/`：網站本體（頁面、題庫、音檔、圖示）
- `netlify/functions/sync.mjs`：跨裝置同步用的小型後端
- `netlify.toml`、`package.json`：Netlify 部署設定
- `deploy.cmd`：一鍵部署（Windows）

## 部署或更新網站

因為有同步功能，不能再用拖曳上傳，要改用 `deploy.cmd`：

1. 在檔案總管雙擊 `deploy.cmd`。
2. 第一次執行會自動下載 Netlify 的部署工具（要幾分鐘），接著開啟瀏覽器請你登入 Netlify 並授權。
3. 回到黑色視窗，它會問要連結到哪個網站：選「Link this directory to an existing site」，再選你原本那個網站。
4. 看到「部署完成」就好了。網址和原本一樣。

之後每次更新，只要雙擊 `deploy.cmd`，不用再登入或選網站。

如果出現錯誤，把黑色視窗的訊息截圖給 Claude 看。

## 開啟跨裝置同步

1. 在第一台裝置（例如電腦）打開網站，到總覽頁最下面的「跨裝置同步」，按「建立同步碼」。
2. 按「複製同步碼」，把這組碼傳到手機。
3. 在手機打開網站，在同一個位置貼上同步碼，按「使用這組同步碼」。

之後每次作答約 3 秒後就會自動同步，打開網站或切回網站時也會自動拉最新進度。兩台裝置各自練習的紀錄都會合併保留。

同步碼就像密碼，知道的人都能讀寫這份進度，請不要外流。只要在某台裝置按「這台裝置停止同步」，那台就不再同步，已存在那台裝置上的進度仍會保留。

## 和 claude.ai 版的差別

| 功能 | claude.ai 版 | 網站版 |
|---|---|---|
| 題庫、練習、模考、錯題本、單字 | 有 | 有 |
| AI 出題、AI 問答 | 有 | 沒有 |
| 同步 | 跟你的 Claude 帳號同步 | 用同步碼在你的裝置之間同步 |
| 加到主畫面、離線使用 | 沒有 | 有 |

兩個版本之間無法自動同步。要把 claude.ai 版的進度搬過來，在 claude.ai 版總覽頁最下面按「下載備份檔」，再到網站版按「從檔案匯入」。

## 加到手機主畫面

- iPhone（Safari）：打開網址 → 分享按鈕 → 加入主畫面。
- Android（Chrome）：打開網址 → 右上角選單 → 安裝應用程式（或加到主畫面）。
